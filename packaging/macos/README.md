# Mac runtime packaging spike

For the current no-Developer-ID private assisted alpha, use the
[verified close-tester candidate and complete ZIP](../../docs/MAC_APP_CLOSE_TESTER_CANDIDATE_2026-10-27.md).
The original spike and public-release gates below are retained as historical and
build references; the close-tester route is separate from notarized distribution.

This builds a local Apple silicon feasibility app. It is **not a public release**:
the default signature is ad-hoc, no notarization is performed, independent setup
acceptance is unfinished, and redistribution terms have not been cleared. Do not send the
generated app to customers as an independently usable beta.

Update, 27 October: first-run model setup is implemented in Settings, including
consent, verified downloads, preparation and recovery controls. See the
[model-setup result](../../docs/MAC_APP_MODEL_SETUP_RESULT_2026-10-27.md) for current
evidence and the current prototype artifact. Independent beta acceptance remains
unfinished; the original runtime-spike instructions below remain useful.

The next slice adds [upgrade/recovery and guided provider setup](../../docs/MAC_APP_UPGRADE_RECOVERY_RESULT_2026-10-27.md).
Recovery copies include the complete local data folder except disposable caches
and locks. Recovery cannot undo remote effects or recover external referenced
files or Keychain credentials. Backups currently have no automatic retention.

Release preparation now has a [notice audit](../../docs/MAC_APP_NOTICES_AUDIT_2026-10-27.md),
[read-only preflight and operator handoff](../../docs/MAC_APP_RELEASE_HANDOFF_2026-10-27.md),
and [draft tester guide](BETA_TESTER_GUIDE.md). The preflight deliberately fails
the current development-signed prototype. Frontend notices are generated by the
latest web build; the existing signed app/DMG has not been rebuilt for that change.

The implementation follows [the packaging plan](../../docs/MAC_APP_PACKAGING_PLAN_2026-10-26.md).
The native launcher owns a Python child, receives readiness from that child,
opens the existing browser editor, and stops the child process group on Quit.
It uses Application Support for data and private caches, drops developer environment
configuration, and never needs the user's development environment at runtime.
The backend locks its data root before loading stores, binds an owned port, and
uses a single-use browser bootstrap with an instance-specific session cookie.

## Build

Build-time prerequisites: an arm64 Mac, Xcode command-line tools, Python 3.12/3.13,
uv 0.9.5 or newer and FFmpeg/FFprobe input executables. The tested build-tool
version is uv 0.9.5; user machines do not need any of these tools. The builder
downloads standalone CPython 3.12.12 and installs locked `local`, `semantic`, and
`vision` dependencies into a private runtime, without copying `.venv` or models.

```sh
python scripts/package_macos.py --uv /absolute/path/to/uv
```

The default workspace is `output/macos-spike/`. It caches a private runtime and
replaces only its own `Clippie.app` on rebuild. The app includes FFmpeg's recursive
local dylib closure with rewritten load commands, removes wheel build-host
RPATHs and staging-interpreter console scripts, audits native dependencies, and
signs nested native code before signing the app. Absolute FFmpeg dependencies
are supported; unresolved input `@rpath` references fail closed.

The launcher is compiled with a provisional macOS 14 target. This is **not** a
supported OS claim for the full dependency graph. The builder derives the app's
`LSMinimumSystemVersion` from the highest native deployment target: the tested
inputs require **macOS 26.2**. Supporting older systems requires different tested
native inputs. `build-manifest.json` records
the source revision/dirty status, lock hash, native inventory, input binary hashes,
removed build-host paths, build-tool version and signature identity. Release
reproducibility still needs pinned standalone archive/binary artifacts and their
license/source delivery inventory; this spike's cached build is not that gate.

The default ad-hoc signature is for local testing and does not enable hardened
runtime. To test hardened execution, pass `--identity` with an installed signing
identity. The verified prototype used Apple Development; Developer ID and
notarization remain separate distribution gates. `--timestamp` requests secure
timestamps for a later distribution-signing workflow.

The Python executable alone receives the entitlements in
`python-entitlements.plist`. The current LLVM/Numba dependency crashed under
hardened runtime without executable-memory permission; `allow-jit` alone did not
resolve it. `allow-unsigned-executable-memory` was needed for the observed LLVM
allocation path. No library-validation exception is enabled. This tradeoff and
the possibility of replacing the JIT dependency remain release-hardening work.
See [Apple's JIT entitlement](https://developer.apple.com/documentation/bundleresources/entitlements/com.apple.security.cs.allow-jit)
and [executable-memory entitlement](https://developer.apple.com/documentation/bundleresources/entitlements/com.apple.security.cs.allow-unsigned-executable-memory).

## Verify

```sh
python scripts/smoke_macos.py output/macos-spike/Clippie.app
```

This launches the native app in smoke mode (temporary empty data, no browser,
no Keychain reads, no recovery or publishing), checks orderly shutdown, imports
the bundled native dependencies, executes MLX compute, and renders a synthetic
captioned MP4/SRT through the actual v3 compositor. It rechecks the app signature
after runtime use. Keys, the production store and existing projects are excluded.

Optional local inference checks use explicitly supplied, already prepared models:

```sh
python scripts/smoke_macos.py output/macos-spike/Clippie.app \
  --whisper-model /absolute/path/to/whisper-small-mlx \
  --speech-fixture /absolute/path/to/test-speech.aiff \
  --embedding-model /absolute/path/to/embeddinggemma-2
```

These do not prove fresh model setup. Hugging Face/Transformers run offline;
desktop transcription refuses an unprepared model instead of downloading a
different model. The model files stay outside the signed application.

Stronger relocation verification:

```sh
python scripts/verify_macos_relocation.py output/macos-spike/Clippie.app \
  --whisper-model /absolute/path/to/whisper-small-mlx \
  --speech-fixture /absolute/path/to/test-speech.aiff \
  --embedding-model /absolute/path/to/embeddinggemma-2
```

This clones the app and explicitly supplied weights into temporary storage,
verifies that its test sandbox really denies source reads and external sockets,
then runs the smoke checks with repository, Homebrew, Conda, Xcode/compiler and
developer cache paths denied. The sandbox is a developer test harness, not a shipped app policy.
Passing it still does not prove operation on another Mac or fresh model setup.

Create a local installer artifact after verification:

```sh
python scripts/package_macos_dmg.py output/macos-spike/Clippie.app
```

It includes an Applications shortcut and a prototype notice, verifies the image,
and records its SHA-256. It does not notarize or publish the artifact. The tested
DMG is about 652 MB, with a 1.44 GB app excluding model weights.

Focused source checks:

```sh
python -m pytest -q tests/test_runtime_paths.py tests/test_desktop.py tests/test_packaged_models.py tests/test_macos_packaging.py
python -m pytest -q packaging/macos/test_launcher.py
```

Remaining gates: independent clean-Mac/Finder acceptance, live first-run model
and provider acceptance, real-project upgrade/recovery drills, normal-work shutdown
and crash/upgrade drills, signed Keychain persistence, Developer ID/notarization,
binary/model/font redistribution, and human listening/editorial quality. Manual
app replacement is the first beta update strategy; automatic updates are deferred.

[uv environment targeting](https://docs.astral.sh/uv/pip/environments/),
